# E-Commerce Sales Analysis

## Project Overview
This project focuses on analyzing e-commerce sales data using SQL and Power BI to identify business insights and sales performance.

## Dataset
- Total Records: 4,999
- Total Columns: 9
- Order ID
- Product Name
- Category
- Quantity
- Unit Price
- Region
- Date
- Time
- Total Amount

## Tools & Technologies
- MySQL
- Power BI
- SQL
- DAX
- Microsoft Excel (if used)

## Business Problems
1. Total Revenue
2. Total Orders
3. Average Order Value (AOV)
4. Highest Revenue Generating Product
5. Revenue by Category
6. Revenue by Region
7. Top 5 Best-Selling Products
8. Monthly Revenue Trend
9. Orders by Time Slot
10. Month-over-Month Revenue Growth

## Key Learnings
- SQL queries and aggregations
- Business problem solving
- Data analysis
- KPI development
- Power BI dashboard development

## Project Objective
To transform raw sales data into meaningful business insights and support data-driven decision-making.
